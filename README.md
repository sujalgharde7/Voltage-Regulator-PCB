# Voltage-Regulator-PCB
I designed and built a custom circuit board that takes unstable electricity and turns it into a steady, safe power supply for electronics. I have made sure all the parts were in the right place, drew the electrical connections safely, and created the final files needed for a factory to manufacture the board.
# Voltage Regulator PCB Design

## Overview

This project presents the design and development of a voltage regulator PCB using KiCad.

The project includes circuit schematic design, PCB layout, component placement, routing, Design Rule Check (DRC), 3D visualization, and generation of manufacturing-ready Gerber files.

## Tools Used

- KiCad
- Schematic Capture
- PCB Layout Design
- PCB Routing
- Design Rule Check (DRC)
- Gerber File Generation

## Project Features

- Voltage regulator circuit design
- Component selection and footprint assignment
- PCB component placement
- Power and signal routing
- PCB board outline design
- Design Rule Check (DRC)
- 3D PCB visualization
- Manufacturing-ready Gerber files

## PCB Design Workflow

1. Circuit schematic creation
2. Component selection
3. Footprint assignment
4. PCB layout creation
5. Component placement
6. Track routing
7. Design Rule Check (DRC)
8. 3D visualization
9. Gerber file generation
